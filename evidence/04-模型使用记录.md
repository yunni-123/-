## 各环节模型使用明细

| 环节 | 模型 | 调用方式 | 说明 |
|---|---|---|---|
| AGH Agent 会话（检查点①③④⑤、B3 全量 19 变体） | `agnes-3.0-flash` | AGH 会话（`-p` 一次性 / TUI / Web workbench `http://127.0.0.1:4177`） | 规划 → 工具调用 → 反馈处理；每会话含多次 `mcp_repro_tools_*` 调用 |
| B2 基线（大模型看报错） | `agnes-3.0-flash` | OpenAI 兼容 API 单次调用（temperature=0） | 每变体 1 次调用：代码 + 单次运行输出 → 根因 JSON |
| 确定性环节（B1、judge、边界测试、MCP 工具本身） | **无模型** | 纯 Python 脚本 | `mcp_server.py` 的 7 个工具全部为确定性代码（无 LLM），保证指标可复现 |

## Token / 耗时量级（实测，2026-10-02）

- B3 单变体会话：约 7–12 次工具调用 + 3–5 轮模型往返；单次 40–300s（首次成功平均 ≈88s，见 `results/agent_results.csv` 与批量日志）。
- B3 全量 19 变体：批量实测 ≈28 min（不含失败重试；期间会话重置 3 次，见 `05-专业验证结果/失败样例分析.md`）。
- B2 全量 19 次单次调用：平均 2.9s/变体（见 `results/b2/*.json` 的 `elapsed_s`）。
- 计费以 Agnes 平台账单为准；竞赛 Key 额度内（`credits.used:0`，平台侧估算计费）。

## 复现说明

- AGH 版本：`/root/agnes-harness` 本地 checkout（commit 见 `evidence/02-环境版本.txt`），Node 以系统 `node` 运行。
- MCP 服务器：`/root/repro-agent-bench/mcp_server.py`（纯 stdlib，`/usr/bin/python3` 启动，stdio JSON-RPC）。
- Skill：`/root/.agh/skills/repro-diagnosis/SKILL.md`（用户级，自动 trust/enable）。
- 会话导出：`agh export <session> --html / --format sharegpt / --format agnes`。
