**日期**：2026-10-02
**团队**：agi队（南京理工大学）· 队长（姓名待定）

## 声明

1. 本项目全部 LLM 调用**仅使用组委会提供的竞赛 Key**（`https://api.agnes-ai.cn/v1`），模型统一为 **`agnes-3.0-flash`**。未使用任何其他厂商/模型（含 DeepSeek、OpenAI 等）生成任何产出内容。
2. 使用 LLM 的环节：
   - **B3 本方案**（AGH agent 会话）：规划、工具调用决策、根因推理、报告生成；
   - **B2 基线**（单次调用）：根因猜测（temp=0，OpenAI 兼容接口）；
   - 项目文档/脚本撰写过程中的辅助（未直接产出评测数字）。
3. **不使用 LLM 的环节**（保证指标客观可复现）：
   - B1 朴素脚本、judge 判分、边界测试、MCP 七个工具（`mcp_server.py` 纯 Python 确定性代码）、基准集生成（`inject_defect.py` / `run_bench.py` / `observations.csv`）。
   - 即：**所有评测数字（准确率/耗时/签名）由确定性脚本计算，模型只负责"诊断推理"，不负责"打分"**。
4. 个人 `sk-` Key 未用于任何产出环节（已建议作废）；竞赛 Key 只用于本项目。
5. 详见 `evidence/04-模型使用记录.md`（逐环节明细 + 耗时/计费说明 + 复现步骤）。
