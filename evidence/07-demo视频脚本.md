# Demo 视频脚本（3 分钟，B4 科研计算可复现性验证智能体）

> 目标：3 分钟内讲清"我们做了什么、凭什么有效、结果如何"。
> 全程录屏 + 旁白；标注 [画面] / [旁白] / [时长]。

## 00:00–0:20 开场（钩子）
- [画面] 黑屏大字："一个'跑通'的程序，也可能是错的。"
- [旁白] "科研代码最常见的事故不是崩溃，而是**静默地算错**：依赖写错照样跑通、随机数没固定两次结果不同、单位换算错了数值只是偏离。传统复现检查只看 exit code，这些全漏掉。"
- [画面] 切到基准集截图：15 个缺陷变体 + 4 个对照组。

## 0:20–1:00 方案（架构图口播）
- [画面] 架构图：AGH agent → `repro-diagnosis` skill（6 步闭环）→ `repro-tools` MCP 七工具（inspect_repo / build_env / run_repo / compare_numbers / diagnose / get_source / verify_fix）→ 科研仓库。
- [旁白] "我们的智能体把'复现'拆成 6 步闭环：查仓库 → 构建隔离环境 → **跑两次** → 比对论文宣称的期望值 → 定位根因 → 最小修复并沙箱验证。每一步都是确定性工具，模型只负责推理，不负责出数字。"

## 1:00–1:50 现场演示（核心）
- [画面] AGH Web workbench（`http://127.0.0.1:4177`）或 TUI。
- [操作] 输入一句话："使用 repro-diagnosis skill 诊断 eval_05（illcond-solve），期望值 relative_residual=1.071e-16, solution_error=2.256e-07。"
- [画面] 滚动展示工具调用链：`inspect_repo → build_env → run_repo ×2 → compare_numbers（两次运行一致但偏离期望）→ diagnose → get_source 定位截断行 → verify_fix 沙箱验证修复后数值回归`。
- [旁白] "注意两处：它跑了**两次**才确认'不是随机性'；它发现程序**没报错**但数值偏离期望——这就是静默截断。最后它在 /tmp 沙箱验证最小修复，数值回到期望。"
- [画面] 定格最后的判定行："判定: root_cause=静默截断 reproducible=false confidence=0.95"。

## 1:50–2:30 结果（三方案对比）
- [画面] `evidence/05-专业验证结果/三方案对比表.md` 截图，逐行指。
- [旁白] "19 个变体全量评测：朴素脚本 0/19（无根因能力）、大模型只看报错 14/19（依赖缺陷 1/4，因为没做环境构建）、我们的方案 **19/19**，4 个对照组零误报。关键差异就一条：谁在做**环境构建 + 两次运行 + 修复验证**——这些是工具链能力，不是模型智商。"
