## 三方案定义

- **B1 朴素脚本**：跑一次 `main.py`，exit=0 → 判可复现；无根因能力（根因恒为「未知」）。
- **B2 大模型看报错**：单次运行输出 + 代码 + requirements 一次性交给 LLM 判根因（无工具、不跑两次、不验证、不修复）。
- **B3 本方案**：AGH agent + `repro-diagnosis` skill + `repro-tools` MCP 七工具，6 步闭环（inspect→build_env→run×2→compare→diagnose→verify_fix），根因由模型基于证据推理，工具链全程确定性。
